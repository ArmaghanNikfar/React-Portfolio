# React Portfolio

```bash
npm install
npm run dev      # development
npm run build    # production build in /dist
```

Edit `src/data.js` to put your own name, skills and projects.

## Deploy to GitHub Pages
Build with `npm run build`, then publish the `dist` folder
(e.g. `npm i -D gh-pages`, add `"deploy": "gh-pages -d dist"` to scripts, run `npm run deploy`).
